# dr.zulfiya — косметология в Шымкенте

[Сайт](https://astana-beauty.notsanzhik.workers.dev) · [Админка](https://astana-beauty.notsanzhik.workers.dev/admin) · [Инструкция для новичка](START_HERE.md)

React, TypeScript, Vite, Cloudflare Worker и D1. Русский и казахский интерфейс, 16 процедур с начальной стоимостью, корзина, выбор даты и свободного времени, защищённая админка, Telegram и отзывы с модерацией.

Кабинет: Шымкент, ул. Жангельдина, 16; ориентир — аптека «Рецепт», 2-й этаж, кабинет 108. WhatsApp кабинета: +7 701 352 84 85.

Автоматических WhatsApp-сообщений и напоминаний нет. Записи приходят в Telegram владельцу сайта; мама не получает уведомлений до явного переключения. WhatsApp открывается по кнопке посетителя. Скриншоты отзывов добавляются через админку и открываются крупнее по нажатию.

Основной код — в `astana-beauty/`. Цены и услуги — `astana-beauty/data/procedures.json`; рабочие часы и контакты — `data/config.json`; тексты — `locales/ru.json` и `locales/kk.json`. На каждую услугу внутри календаря пока выделяется 60 минут, длительность посетителям не показывается.

Для запуска установите Node.js 22.13+, в папке `astana-beauty` выполните `npm ci`, затем в Windows запустите `Start-Beauty.cmd` из корня. Подробные инструкции для других систем, Telegram и деплоя — в [START_HERE.md](START_HERE.md).

Проверки в папке проекта: `npm run typecheck`, `npm test`, `npm run build`. Секреты, локальные базы и данные клиентов исключены из репозитория. Деплой выполняется вручную; GitHub сам по себе его не запускает.
