# Косметологический кабинет в Астане

Полный исходный код сайта с записью на процедуры, двумя языками (русский и казахский), защищённой админкой и уведомлениями в Telegram.

**Сайт:** https://astana-beauty.notsanzhik.workers.dev  
**Админка:** https://astana-beauty.notsanzhik.workers.dev/admin

## Что входит

- React + TypeScript + Vite — адаптивный сайт в бело-розовой палитре.
- Cloudflare Worker и D1 — сервер, база записей и защита от пересечения интервалов.
- Выбор нескольких процедур, расчёт суммы и длительности, доступные слоты в Asia/Almaty.
- Telegram — уведомление о новой записи и отмена с подтверждением.
- Админка — вход по паролю, фильтры и отмена записи.
- WhatsApp через Twilio — подготовлен в коде, сейчас выключен; подключение необязательно.
- Миграции базы, 16 серверных тестов, файлы переводов и инструкция для новичка.

## Быстрый запуск

1. Установите Node.js LTS с https://nodejs.org/ (нужна версия 22.13 или новее).
2. Скачайте репозиторий через **Code → Download ZIP** и распакуйте его.
3. Откройте терминал в папке `astana-beauty` и выполните `npm ci`.
4. В Windows вернитесь в корень и запустите `Start-Beauty.cmd` двойным щелчком.
5. Откройте http://127.0.0.1:5173. Пароль локальной админки находится в строке `ADMIN_PASSWORD` файла `astana-beauty/.dev.vars`, который создаст скрипт запуска.

Подробные команды для других систем, настройка Cloudflare, Telegram и деплой: **[START_HERE.md](START_HERE.md)** или **[README проекта](astana-beauty/README.md)**.

## Где редактировать

| Что | Файл |
| --- | --- |
| Процедуры, описания, цены и длительность | `astana-beauty/data/procedures.json` |
| Рабочие часы, выходные, адрес и контакты | `astana-beauty/data/config.json` |
| Тексты на русском и казахском | `astana-beauty/locales/ru.json`, `astana-beauty/locales/kk.json` |
| Отзывы | `astana-beauty/data/reviews.json` |
| Фото и сертификаты | `astana-beauty/public/images/`, конфигурация в `data/config.json` |
| Сервер и интеграции | `astana-beauty/worker/` |
| Схема базы и миграции | `astana-beauty/db/`, `astana-beauty/drizzle/` |
| Пример переменных окружения | `astana-beauty/.env.example` |

## Текущее состояние

На момент сохранения кода публичная запись закрыта, пока не внесены настоящие контакты, фото и цены. Админка и тестовая запись доступны владельцу. Telegram подключён к тестовому аккаунту владельца; WhatsApp выключен. Название Aru, некоторые тексты, отзывы и цены — демонстрационные данные, которые нужно заменить перед открытием записи.

Пароли, токены, OAuth-доступы и данные клиентов не входят в репозиторий. Они хранятся в переменных Cloudflare и локальных файлах, исключённых через `.gitignore`. В `wrangler.jsonc` сохранены только несекретные параметры текущего проекта; для другого аккаунта нужно создать свою D1-базу и заменить её идентификатор по инструкции.

## Проверка кода

В папке `astana-beauty` после установки зависимостей:

```sh
npm test
npm run build
```

Развёртывание выполняется вручную командами из инструкции. Загрузка кода в GitHub сама по себе не изменяет работающий сайт.
