# Логотип dr.zulfiya

Выбран второй вариант: розовая монограмма dZ. В шапке сайта на компьютере и телефоне используется только монограмма, без надписи.

## Исходные изображения

- `monogram.png` — отдельный знак на прозрачном фоне.
- `wordmark.png` — фирменная надпись на прозрачном фоне.
- `logo-horizontal.png` — знак и название в одну строку, для других материалов.
- `logo-approved.png` — утверждённая композиция на белом фоне.
- `PROMPTS.json` — запросы, использованные во встроенном ImageGen для подготовки вариантов.

Это растровые PNG, не векторные SVG. Все файлы сохранены в исходном разрешении.

Оптимизированные изображения для сайта и значки вкладки находятся в [public/brand](../../public/brand/). Их отображение настраивается в [src/brand.css](../../src/brand.css); компонент `Brand` находится в [src/main.tsx](../../src/main.tsx).
