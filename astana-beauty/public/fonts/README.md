# Noto Sans

Локальный шрифт сайта: `noto-sans.woff2`, прямое начертание, переменный вес 400–700, обычная ширина 100.

Источник: официальный репозиторий Google Fonts, файл [NotoSans[wdth,wght].ttf](https://github.com/google/fonts/blob/main/ofl/notosans/NotoSans%5Bwdth%2Cwght%5D.ttf). Загружен 13 октября 2026 года. Исходный SHA-256: `bfb7bb691513f12e734dc346c03a03f784912432d7e3fa8e56efcf906fe86b3d`.

Сохранены латинские и кириллические символы, в том числе казахские Әә Ғғ Ққ Ңң Өө Ұұ Үү Һһ Іі, знаки препинания, валюты и распространённые символы. Все 126 различных букв из файлов `locales/*.json` и `data/*.json` проверены по таблице символов готового WOFF2. Размер: 127 896 байт, 1 424 символа Unicode. Файл создан с помощью FontTools 4.66.1 и Brotli 1.2.0; ширина зафиксирована, ненужные символы исключены.

Шрифт распространяется по SIL Open Font License 1.1. Полный текст и сведения об авторстве сохранены в `OFL.txt`.
