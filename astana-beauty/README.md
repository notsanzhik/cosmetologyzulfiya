# dr.zulfiya — косметология в Шымкенте

Сайт: https://astana-beauty.notsanzhik.workers.dev  
Админка: https://astana-beauty.notsanzhik.workers.dev/admin  
Приватный код: https://github.com/notsanzhik/cosmetologyzulfiya

Техническое имя `astana-beauty` сохранено для совместимости с уже созданными Worker, базой и ботом. На сайте указаны Шымкент и dr.zulfiya.

## Устройство сайта

React + TypeScript + Vite показывают интерфейс. Cloudflare Worker проверяет данные, Cloudflare D1 хранит записи, занятые интервалы, отзывы и очередь Telegram. База локально работает через Wrangler — устанавливать отдельную СУБД не нужно.

Клиент собирает корзину процедур, выбирает дату и свободное время, указывает имя и телефон. Пока календарь выделяет **60 минут на каждую процедуру** и 15 минут между визитами. Длительность клиентам не показывается. На один визит можно выбрать до четырёх процедур. Проверка пересечений выполняется на сервере: запись и уникальные 15-минутные интервалы сохраняются одной транзакцией, при конфликте всё откатывается.

Telegram присылает имя, телефон, процедуры, начальную сумму, дату и время. Отмена требует одноразового подтверждения и освобождает время. Пока бот подключён к аккаунту владельца сайта: мама не получает сообщений до явного переключения.

**Автоматических WhatsApp-сообщений и напоминаний за три часа нет.** Старые задачи тоже не отправляются. Кнопка WhatsApp открывает чат только после нажатия посетителем. Twilio и WhatsApp Business API не нужны.

Отзывы клиентов ждут модерации. Админ может опубликовать или скрыть отзыв, добавить текст либо скриншот. Браузер сжимает изображения; они хранятся в D1 без отдельного файлового сервиса. Скриншот открывается крупнее по нажатию.

## Расходы

Используется существующий бесплатный тариф Cloudflare в рамках его квот. Текущие ограничения смотрите в [Workers](https://developers.cloudflare.com/workers/platform/pricing/) и [D1](https://developers.cloudflare.com/d1/platform/pricing/). Отдельный домен необязателен: адрес `workers.dev` работает. Для обычных Telegram-уведомлений отдельного платного сервиса нет. Автоматизация платного WhatsApp удалена.

## Запуск для новичка

1. Установите Node.js LTS с https://nodejs.org/ — версия 22.13 или новее.
2. В GitHub нажмите **Code → Download ZIP**, распакуйте архив.
3. Откройте терминал в папке `astana-beauty` и выполните `npm ci`.
4. В Windows запустите `Start-Beauty.cmd` из родительской папки. Скрипт применит локальные миграции, создаст `.dev.vars` со случайными паролями, если файла ещё нет, и запустит сайт.
5. Откройте http://127.0.0.1:5173. Админка: http://127.0.0.1:5173/admin. Её пароль — значение `ADMIN_PASSWORD` из локального `.dev.vars`.

Ручной запуск вместо Windows-скрипта:

```sh
npm ci
```

Скопируйте `.env.example` в `.dev.vars` (`Copy-Item .env.example .dev.vars` в PowerShell или `cp .env.example .dev.vars` в другом терминале). Замените `replace-…` на случайные длинные строки. Установите `BOOKING_ENABLED=true`, `SITE_URL=http://127.0.0.1:5173`; для локального теста оставьте `NOTIFICATIONS_ENABLED=false`.

```sh
npm run db:local
npm run dev
```

Локальная база отделена от облачной. `.dev.vars`, `.wrangler`, пароли и базы не добавляются в Git.

## Cloudflare и деплой

Текущий аккаунт и D1 уже настроены. Для переноса в другой аккаунт:

1. Зарегистрируйтесь на https://dash.cloudflare.com/, выберите Workers Free.
2. Выполните `npx wrangler login`, завершите вход в браузере.
3. Выполните `npx wrangler d1 create astana-beauty-db`.
4. В `wrangler.jsonc` замените `account_id` и `database_id` на свои. Оставьте `binding: "DB"`. При необходимости измените имя Worker.
5. Примените все миграции: `npm run db:remote`.
6. В Cloudflare откройте Worker → **Settings → Variables and Secrets**. Создайте Secrets из `.env.example`: `ADMIN_PASSWORD`, `SESSION_SECRET`, `CRON_SECRET`, `TELEGRAM_WEBHOOK_SECRET`, затем секреты Telegram. Пароль — минимум 16 символов, остальные случайные секреты — минимум 32. Не используйте примерные значения.
7. Укажите `SITE_URL` с адресом своего сайта, `BOOKING_ENABLED=true` и `NOTIFICATIONS_ENABLED=true`.
8. Выполните:

```sh
npm run typecheck
npm test
npm run build
npm run deploy
```

В конфиге стоит `keep_vars: true`: деплой сохраняет переменные из Cloudflare. После публикации проверьте их. Публичная запись работает только при `BOOKING_ENABLED=true`.

## Telegram

Бот проекта: https://t.me/DrZulfiyabot. Пока получателем остаётся владелец сайта. Для нового бота откройте https://t.me/BotFather, отправьте `/newbot`, задайте название и уникальное имя, заканчивающееся на `bot`.

1. Добавьте токен в `TELEGRAM_BOT_TOKEN` в Cloudflare Secrets. Локально — в `.dev.vars`, чтобы воспользоваться помощником. Не публикуйте токен в GitHub.
2. Будущий получатель открывает бота и нажимает **Start**.
3. До установки webhook выполните `node scripts/telegram.mjs ids`. Помощник покажет числовые ID личных чатов. Введите нужные значения в `TELEGRAM_CHAT_ID` и `TELEGRAM_OWNER_ID` в Cloudflare. Уже установленный webhook мешает `getUpdates`, поэтому для существующего бота сначала согласуйте переключение и используйте его настроенный аккаунт.
4. Установите длинный случайный `TELEGRAM_WEBHOOK_SECRET` в Cloudflare и локальную `.dev.vars`.
5. Зарегистрируйте webhook и проверьте его:

```sh
node scripts/telegram.mjs register https://ВАШ-АДРЕС-САЙТА
node scripts/telegram.mjs status
```

Помощник читает токен из `.dev.vars` или окружения и не печатает его. Отменять запись через кнопки может только указанный `TELEGRAM_OWNER_ID` в указанном личном чате. Подтверждение одноразовое и действует пять минут.

Cron каждые пять минут обслуживает очередь Telegram. Если сервис мог получить сообщение, но ответ потерялся, оно получает статус «Требует проверки» и автоматически не повторяется. Это предотвращает дубли: проверьте чат вручную.

## Где редактировать

| Что | Файл / место |
| --- | --- |
| Процедуры, категории, цены, названия и описания на двух языках | `data/procedures.json` |
| Внутренний интервал услуги | `duration` в том же файле, минуты кратные 15 |
| Рабочие часы, перерывы, выходные, часовой пояс | `data/config.json` |
| Телефон, WhatsApp, Instagram и ссылки карты | `contact` в `data/config.json` |
| Адрес, бренд, тексты интерфейса | `locales/ru.json`, `locales/kk.json` |
| Фото мастера | Файл в `public/images`, затем путь `images.master` в конфиге |
| Сертификаты | Файлы в `public/images`, затем `certificates` с `src` и заголовками `ru`/`kk` |
| Новые отзывы и скриншоты | Админка → «Отзывы» |
| Статические отзывы | `data/reviews.json`, показываются только записи с `sample: false` |
| Секреты | Cloudflare Secrets, локально `.dev.vars` |

Цена — целое число тенге. `priceType: "from"` обозначает «от», `"fixed"` — фиксированную стоимость. Для неизвестной цены используйте **`price: null` и `priceType: "on_request"`**, а не ноль. В смешанной корзине показывается начальная сумма известных позиций плюс пометка «цена уточняется». Числовое `total` в базе — сумма известных начальных цен; типы цен сохраняются в снимке услуг. Изменение прайса не меняет уже созданные записи.

Мезонити указаны «от 1 000 ₸» без утверждения, что это цена за штуку. Четыре зоны контурной пластики представлены отдельными процедурами «от 30 000 ₸» с зависимостью от препарата.

Чтобы добавить процедуру, скопируйте объект в `procedures`, задайте уникальный `id`, существующую `category`, оба перевода, `duration`, `price`, `priceType`, `placeholderPrice: false` и `enabled: true`. Сохраняйте ID существующих услуг, если их смысл не изменился.

## Отзывы и скриншоты

Посетитель нажимает «Оставить отзыв», вводит имя и текст, подтверждает согласие на публикацию. В админке отзыв имеет статус «На проверке». «Опубликовать» показывает его на сайте, «Скрыть» убирает текст и изображение с публичной страницы, сохраняя запись для владельца.

Для скриншота откройте «Добавить отзыв или скриншот», выберите JPEG, PNG или WebP до 8 МБ. Браузер сожмёт файл; сервер принимает не больше 750 КБ и проверяет формат. Подтвердите разрешение клиента, сохраните и затем опубликуйте. Перед загрузкой уберите сведения, которые клиент не разрешал публиковать.

## Чек-лист проверки

- На русском и казахском проверьте «от»/«бастап» и «цена уточняется».
- Выберите процедуры, дату и слот. Для двух услуг занято два часа плюс 15 минут перерыва.
- Создайте запись: подтверждение содержит услуги, дату, время и начальную сумму; в Telegram приходит одно сообщение.
- Повторите запись на пересекающееся время: сервер должен отклонить её.
- Отмените запись через Telegram с подтверждением и через админку. Проверьте освобождение слотов.
- Автоматических сообщений WhatsApp и напоминаний быть не должно. Обычная кнопка должна вести на нужный номер.
- Отправьте отзыв: до проверки он не виден. Опубликуйте и скройте его.
- Загрузите скриншот, проверьте увеличение. Без входа в админку загрузка должна быть недоступна.
- Для проверки Telegram без открытия публичной записи используйте `/admin/test-booking`; после проверки отмените тестовую запись.

Команды проверки: `npm run typecheck`, `npm test`, `npm run build`. Пароли, токены и клиентские данные не должны находиться в репозитории или архиве кода.
